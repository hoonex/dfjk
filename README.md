# Recall Rush

영어 스피킹 수행평가용 단순 암기 웹앱입니다.

- 11개 문항 중 **랜덤 5개** 실전 연습
- 질문 전체가 아니라 **앞부분 cue**를 보고 답변 회상
- 답변 직접 타이핑 + 대소문자/문장부호 무시 비교
- 힌트 / 정답 보기 / 틀린 문장 자동 재출제
- 세션 XP, 일일 streak를 `localStorage`에 저장
- 모바일/태블릿/데스크톱 반응형
- 외부 라이브러리 없이 정적 HTML/CSS/JS로 실행

## 실행

`index.html`을 브라우저에서 열거나 정적 서버로 실행하면 됩니다.

```bash
python3 -m http.server 8080
```

## 문제 데이터

문제와 답변은 `app.js`의 `QUESTIONS` 배열에 있습니다.

## 디자인

학습 게임의 빠른 문제 → 입력 → 즉시 피드백 → 다음 문제 흐름을 참고했지만, 브랜드·색상·마스코트·문구는 독자적으로 구성했습니다. 마스코트 이름은 **모리(Mori)** 입니다.
